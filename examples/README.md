# Examples

| Folder | What's inside |
|---|---|
| `specs/<family>/<type>.json` | One spec for each of the 42 types, grouped into `systems`, `process`, `data-platform`, `structure` and `charts`. These double as test fixtures. |
| `gallery/` | Generated by `npm run gallery` (git-ignored): one HTML page per spec plus `index.html`. |
| `media/` | Exported samples (png, jpg, svg, gif, mp4, webm) used by the README. |

Render one example:
`node skills/seecode/scripts/seecode.mjs render examples/specs/systems/architecture.json`

Browse them all:
`npm run gallery`, then open `examples/gallery/index.html`.
