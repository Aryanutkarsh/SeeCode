---
description: Show or change SeeCode settings (theme, motion, export formats, brand profile)
argument-hint: [key value] [--global]
---
Without arguments, run `node "${CLAUDE_PLUGIN_ROOT}/skills/seecode/scripts/seecode.mjs" config status` and show the settings as a short list.
With arguments, run `node "${CLAUDE_PLUGIN_ROOT}/skills/seecode/scripts/seecode.mjs" config set $ARGUMENTS` and confirm the change. See `skills/seecode/references/settings.md`.
