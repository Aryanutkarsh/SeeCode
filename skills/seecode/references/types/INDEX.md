# Type index

Pick a type, then read `types/<type>.md`.

**Systems:**
- `architecture`: components and connections
- `high-level`: 4–7-box overview for non-engineers
- `deployment`: where things run (hosts, regions)
- `dependency`: what imports or depends on what
- `architecture-delta`: what a change adds, removes or alters
- `it-state`: current IT landscape with health status
- `uml-class`: classes and interfaces
- `er`: entities and cardinality
- `db-schema`: tables and FK columns

**Process:**
- `flowchart`: decisions and branches
- `sequence`: messages between actors over time
- `state`: states and transitions
- `swimlane`: who does which step
- `process`: short linear numbered steps
- `data-flow`: data moving through stages
- `journey`: user steps and emotion curve
- `timeline`: dated events
- `gantt`: work over time
- `kanban`: items by status
- `story-map`: backbone and release slices
- `loop`: reinforcing cycle or flywheel

**Data platform:**
- `medallion`: bronze/silver/gold layers
- `dp-integration`: sources → integration → platform → serving
- `dp-security-matrix`: roles × data access

**Structure:**
- `tree`: parent → children
- `org-chart`: people and teams
- `nested`: containment and scopes
- `layers`: a stack
- `isometric`: any object in 3D, from a description (a chair, a laptop)
- `exploded`: parts of one thing, lifted apart (isometric)
- `isometric-plan`: a floor or site seen from above (isometric)
- `venn`: overlaps
- `pyramid`: ranking, or `funnel` for drop-off
- `quadrant`: a 2×2
- `fishbone`: root causes
- `wardley`: evolution × visibility

**Charts:**
- `bar`: compare amounts (`dumbbell`, `marimekko`)
- `line`: change over time (`slopegraph`, `bump`, `streamgraph`, `ridgeline`)
- `scatter`: two measures (`bubble`, `beeswarm`)
- `waterfall`: running total
- `treemap`: part of whole
- `heatmap`: intensity grid
- `radar`: profile on shared axes
- `polar`: cyclical values
- `sankey`: flow volumes

Other variants:
- `quadrant-consultant`
- `loop-terminal`
- `sequence-oauth`
- `state-lifecycle`
- `tree-block-decomposition`
- `high-level-vertical`
